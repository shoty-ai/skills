# Shoty skills

Agent skills for [Shoty](https://shoty.ai), the desktop video editor.

| Skill | What it teaches |
|---|---|
| [`shoty`](skills/shoty/SKILL.md) | Drive Shoty with the `shoty` command: open or create projects, edit, look at frames, and export videos. |

## Install

```bash
npx skills add shoty-ai/skills -g
```

Pick the agents to install it for (Claude Code, Codex, Antigravity CLI, and
others). Shoty can also run this for you: Preferences → Advanced → Command line.

The `shoty` command comes with Shoty. Turn it on in Shoty → Preferences →
Advanced → "Allow command-line control".
